# Q12: Healthcare Star Schema Data Model Solution

## Problem Statement
A healthcare organization builds a Star Schema linking FactBilling with Dimension tables (DimPatient, DimDoctor, DimDepartment).

## Visuals Configured
1. **Fact Metrics**: Total Treatment Cost, Average Treatment Cost, Total Patient Encounters.
2. **Dimension Department Bar Chart**: Revenue aggregated across department dimension.
3. **Dimension Doctor Column Chart**: Performance aggregated across doctor dimension.
4. **Denormalized Fact/Dim View Table**.
