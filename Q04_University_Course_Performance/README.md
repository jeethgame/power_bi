# Q04: University Course Performance Solution

## Problem Statement
A university maintains student, faculty, course, enrollment, and examination data and analyzes academic performance.

## Visuals Configured
1. **Cards**: Average Marks, Total Students Enrolled, Pass Percentage %.
2. **Clustered Bar Chart**: Course-wise Average Marks.
3. **Donut Chart**: Grade Distribution (A, B, C, F).
4. **Column Chart**: Faculty-wise Student Performance.
5. **Detail Table**: Student Ranking & Grade Record.
